# 银行反欺诈告警关系分析与案件调查平台

基于 React、Mantine、Redux Toolkit、RTK Query、React Router、React Flow、Vite 和 TypeScript 实现的中文前端项目。项目使用浏览器 `localStorage` 模拟服务端数据库，不依赖外部后端即可运行。

## 功能

- 告警中心：关键词、风险等级、状态和渠道组合筛选，批量关联案件或排除。
- 案件工作台：案件列表、风险状态、调查工作量与统一判定结果概览。
- 关系图谱：账户、设备、IP、商户关系布局，节点拖动持久化，关系解释与弱关联区分。
- 联动时间轴：交易、告警和证据按时间排序，点击后高亮对应关系。
- 证据台账：稳定证据编号 + 完整版本链，支持“补版本”；旧版本标记被取代但不删除。
- 判定批次（可恢复）：证据台账、结论复核、告警关联统一走批次；每步落盘并记录 `stepsCompleted`，写库中断后从最近完整步骤续跑，重试只补未完成项，审计按 `dedupKey` 幂等，不会多出版本或审计。
- 结论版本：提交时冻结所依据的证据版本与告警快照；证据发布新版本后，草稿与待复核结论失效（依据失效·待重算），已通过版本保留提交快照。
- 并发提交：两位调查员同时提交同一案件时，占座阶段原子决定先到者入库、后到者保留草稿；落败草稿同时保留双方依据，可对照后重算。
- 历史回填：旧结论缺少证据版本时，按结论提交时间回放证据台账；试不出证据版本的标记“待补证”，复核不能通过。
- 统一结果出口：案件页、概览、案件队列和 JSON/CSV 导出共用同一判定结果（`caseView`）。
- 审计报告：操作人、时间、批次不可变留痕，支持审计与判定结果的 JSON、CSV 导出、写库中断演练及演示数据重置。

## 技术栈

- React 19 + TypeScript
- Mantine 9
- Redux Toolkit + RTK Query
- React Router
- React Flow
- Vite

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:18458`。

## 构建

```bash
npm run build
npm run preview
```

`npm run build` 会先执行严格 TypeScript 检查，再生成 Vite 生产构建。

判定批次的端到端不变量（提交冻结、补版失效、并发落败、中断续跑幂等、旧数据回填）可用以下命令校验：

```bash
npm run engine:check
```

## 数据说明

数据保存在浏览器 `localStorage` 的 `bank-fraud-investigation-db-v2` 键下。首次打开写入演示数据；若检测到旧版 v1 数据，会自动迁移：证据补出 `versions` 版本链，旧结论按提交时间回填证据版本，无法匹配的标记“待补证”。证据补版、结论提交/复核、告警关联与中断批次都会持久化；“审计与报告”页面可以重置全部演示数据并清除中断演练标记。
