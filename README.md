# 银行反欺诈告警关系分析与案件调查平台

基于 React、Mantine、Redux Toolkit、RTK Query、React Router、React Flow、Vite 和 TypeScript 实现的中文前端项目。项目使用浏览器 `localStorage` 模拟服务端数据库，不依赖外部后端即可运行。

## 功能

- 告警中心：关键词、风险等级、状态和渠道组合筛选，批量关联案件或排除。
- 案件工作台：案件列表、风险状态和调查工作量概览。
- 关系图谱：账户、设备、IP、商户关系布局，节点拖动持久化，关系解释与弱关联区分。
- 联动时间轴：交易、告警和证据按时间排序，点击后高亮对应关系。
- 证据台账：来源、发生时间、提交人、附件标识、证据强度和版本记录；同一份证据可补充新版本，旧版本永久保留并标记“已被替代”。
- 结论版本与判定批次：提交结论（含草稿）时冻结所依据的证据版本与告警快照；证据补充新版本后，引用旧版本的草稿与待复核结论自动失效待重算，已通过/已退回版本保留提交快照。
- 并发提交：两位调查员同时提交同一案件时先到版本入库进入复核，后到提交保留为“并发冲突草稿”，页面可并排查看两边冻结的证据与告警依据。
- 可恢复批次：证据登记/补充、结论提交、复核、告警关联均走步骤级持久化的判定批次；写库中断后可从最近完整批次继续，重试只补未完成步骤，不多出版本或审计。审计页提供“写库中断演练”。
- 旧结论迁移：没有证据版本的历史结论按提交时间回填证据版本与告警快照；回填不到证据的结论标记“待补证”，案件转为补证。
- 统一判定视图：案件页、概览和 JSON/CSV 导出共用同一份判定状态；案件有效状态由依据新鲜度统一推导并回写。
- 审计报告：操作人、时间、批次号不可变留痕，支持判定报告 JSON/CSV 导出及演示数据重置。

## 判定批次与恢复

- 每个判定批次（`DecisionBatch`）包含若干带状态的步骤，每完成一步立即落盘；中断后通过同一 `requestId` 恢复，已完成步骤跳过，未完成步骤继续。
- 结论、证据、审计均使用基于 `requestId` 的确定性 ID，恢复重试天然幂等。
- 演示：在“审计与报告”页选择中断步骤（如“审计写入前”）并布置，随后执行任意判定操作即可触发写库中断；页面顶部出现黄色恢复横幅，点击“从最近完整批次继续”即可补完，批次表展示每步进度。
- 无头验证脚本覆盖回填、冻结/失效、并发、中断恢复、幂等等场景：

```bash
node scripts/verify-batches.mjs
```

## 技术栈

- React 19 + TypeScript
- Mantine 9
- Redux Toolkit + RTK Query
- React Router
- React Flow
- Vite

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:18458`。

## 构建

```bash
npm run build
npm run preview
```

`npm run build` 会先执行严格 TypeScript 检查，再生成 Vite 生产构建。

## 数据说明

首次打开时会将演示案件写入 `localStorage`。后续新增证据、结论、关系节点和状态流转会持久化到同一浏览器存储；“审计与报告”页面可以重置全部演示数据。
